# 佐々木歯科医院 ブログ執筆指示書（医療広告ガイドライン厳格対応版）

## 1. 基本ルール

### 1.1 準拠法令・ガイドライン
- 医療法第6条の5（医療広告規制）
- 厚生労働省「医療広告ガイドライン」（令和5年改定版）
- 厚生労働省「医療広告ガイドラインに関するQ&A」

### 1.2 文体ルール
- **です・ます調**で統一する
- 専門用語を使用する場合は、必ず平易な説明を併記する
  - 例: 「顎位矯正（あごの位置を正しい位置に戻す矯正治療）」
  - 例: 「K7マシン（顎の動きや筋肉の活動を科学的に計測する装置）」
- 1文は80文字以内を目安とし、読みやすさを重視する
- 断定的・煽動的な表現を避け、客観的な情報提供を心がける

### 1.3 記事構成ルール
- 必ず「監修者情報」を記事末尾に記載する
- 自費診療に関する記載がある場合は「限定解除要件ブロック」を必ず挿入する
- 公的出典への参照を最低1件以上含める

## 2. 絶対NG表現一覧

以下の表現はいかなる文脈でも使用禁止とする。

### 2.1 他院の商標・固有技術名
| NG表現 | 理由 |
|---|---|
| MEAW | 他院の矯正技術名称であり、当院の治療方針と異なる |
| meaw | 同上（小文字表記も不可） |

### 2.2 誇大広告・虚偽広告に該当する表現
| NG表現 | 理由 |
|---|---|
| 絶対治る | 治療効果の保証（医療法違反） |
| 必ず成功 | 治療効果の保証（医療法違反） |
| 100%安全 | リスクがゼロであるかのような誤認を招く |
| 完全無痛 | 痛みがゼロであるかのような誤認を招く |
| 痛くない治療 | 無痛を保証する表現（「痛みに配慮した治療」は可） |

### 2.3 比較優良広告に該当する表現
| NG表現 | 理由 |
|---|---|
| 日本一 | 客観的根拠のない最上級表現 |
| 最高 | 客観的根拠のない最上級表現 |
| No.1 | 客観的根拠のない最上級表現 |
| 最先端 | 客観的根拠のない優位性の主張 |
| 唯一 | 客観的根拠のない排他的表現 |
| 京都で一番 | 客観的根拠のない地域最上級表現 |

### 2.4 その他の禁止事項
- **Before/After写真の掲載禁止**: 治療前後の比較写真は、患者の誤認を招く恐れがあるため掲載しない
- **体験談・口コミの引用禁止**: 患者の主観的な体験談は医療広告として認められない
- **他院との比較禁止**: 他院を名指しまたは示唆する比較表現は一切使用しない
- **芸能人・有名人の治療歴の示唆禁止**: 「芸能人も通う」等の表現は使用不可

## 3. 自費診療記載ルール

### 3.1 費用表記の統一形式
自費診療の費用を記載する場合は、以下の形式を厳守する:

```
○○円〜（税込・自由診療のため保険適用外）
```

- 必ず税込価格を記載する
- 「自由診療のため保険適用外」を必ず付記する
- 費用に幅がある場合は下限を示し「〜」を付ける
- 具体的な費用が不明な場合は「費用の詳細は医院までお問い合わせください（自由診療のため保険適用外）」と記載する

### 3.2 費用記載が必要なケース
以下の治療に言及する場合は、費用情報の記載を必須とする:
- 歯列矯正（顎位矯正を含む）
- インプラント（ジルコニアインプラントを含む）
- メタルフリー治療（ジルコニア・セラミック等）
- マイクロスコープを使用した精密治療（自費の場合）
- その他、保険適用外のすべての治療

## 4. リスク・副作用明記ルール

### 4.1 基本原則
自費診療に関する記事では、対象治療のリスク・副作用を必ず具体的に記載する。
「リスクがあります」のような抽象的な記述は不可。具体的な症状・可能性を列記すること。

### 4.2 治療別リスク記載例

#### 歯列矯正
- 治療中に痛みや違和感が生じる場合があります
- 歯の移動に伴い、歯根吸収が起こる可能性があります
- 矯正装置の装着により、虫歯や歯周病のリスクが高まる場合があります
- 治療後に後戻りが生じる可能性があり、保定装置の使用が必要です
- 治療期間や結果には個人差があります

#### インプラント
- 外科手術を伴うため、術後に腫れ・痛み・出血が生じる場合があります
- 顎の骨の状態によっては、治療が適用できない場合があります
- インプラント周囲炎のリスクがあり、定期的なメンテナンスが必要です
- 喫煙・糖尿病等の全身状態により、治癒が遅れる場合があります
- 上顎洞や神経への影響が生じる可能性があります（まれ）

#### メタルフリー治療（ジルコニア・セラミック）
- 天然歯に比べて硬いため、対合歯を傷める可能性があります
- 強い衝撃により、破折・欠けが生じる場合があります
- 色調が天然歯と完全に一致しない場合があります
- 歯ぎしり・食いしばりの強い方は破損リスクが高まります

## 5. 限定解除要件ブロック（テンプレート）

自費診療に言及する記事には、以下のブロックを記事末尾（まとめセクションの後、監修者情報の前）に必ず挿入する。

```
---
**治療についての重要事項**

- **治療内容**: [具体的な治療名と概要]
- **費用**: ○○円〜（税込）※自由診療のため保険適用外
- **治療期間・回数の目安**: [目安]
- **リスク・副作用**: [具体的なリスクを列記]
- ※自由診療は公的医療保険が適用されない診療です。
- ※治療効果には個人差があります。

**佐々木歯科医院**
副院長 佐々木 継泰

- 国際顎頭蓋機能学会 日本部会 認定医
- 国際顎頭蓋機能学会 マスター
- 京都歯科医療技術専門学校 運営委員
- 京都市立大枝小学校 学校医
---
```

### 5.1 テンプレート使用上の注意
- `[具体的な治療名と概要]` は記事の主題に合わせて必ず具体化する
- `○○円〜` は実際の費用を記入する。不明な場合は「詳細は医院までお問い合わせください」とする
- `[目安]` は一般的な治療期間・回数を記入する
- `[具体的なリスクを列記]` は第4章のリスク記載例から該当するものを選定・記入する
- 複数の治療に言及する記事では、治療ごとにブロックを分けて記載する
